Simple hello world module to start#

This hello world kernel module has been developed as a starting point. It is also considered that a buildroot(BR) and kernel(external to BR) has been previously built.

Prerequisites#

Before we start, ensure you have:

  • Buildroot environment properly configured and built
  • QEMU virtualization setup for your target architecture
  • External Linux kernel built with module support enabled
  • Cross-compilation toolchain (provided by Buildroot)

QEMU Options Explained#

  • qemu-system-x86_64 - Emulates x86_64 (64-bit Intel/AMD) architecture
  • -kernel /path/to/bzImage - Specifies the Linux kernel binary file
  • -drive file=rootfs.ext2,if=virtio,format=raw - Mounts filesystem image as virtio block device
    • file= - Path to the filesystem image
    • if=virtio - Uses virtio interface for better performance
    • format=raw - Specifies raw disk image format
  • -append "console=ttyS0 root=/dev/vda rw" - Kernel command line parameters
    • console=ttyS0 - Redirects console output to serial port
    • root=/dev/vda - Root filesystem is on virtio disk device
    • rw - Mount root filesystem as read-write
  • -netdev user,id=net0 - Creates user-mode network backend (NAT)
  • -device e1000,netdev=net0 - Emulates Intel E1000 network card
  • -nographic - Disables graphical output, uses text console only
  • -enable-kvm - Enables KVM hardware acceleration (if available)
  • -m 512M - Allocates 512MB of RAM to the virtual machine

#include <linux/init.h>
#include <linux/module.h>
#include <linux/kernel.h>

static int __init hello_init(void)
{
    printk(KERN_INFO "Hello World from kernel module!\n");
    printk(KERN_INFO "Module loaded successfully\n");
    return 0;  // Return 0 for successful initialization
}

static void __exit hello_exit(void)
{
    printk(KERN_INFO "Goodbye World from kernel module!\n");
    printk(KERN_INFO "Module unloaded successfully\n");
}

module_init(hello_init);
module_exit(hello_exit);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("Your Name <your.email@example.com>");
MODULE_DESCRIPTION("A simple Hello World kernel module");
MODULE_VERSION("1.0");

Understanding the Code#

Key Components#

  • __init and __exit macros: Tell the kernel which functions to call during load/unload
  • module_init() and module_exit(): Register the initialization and cleanup functions
  • printk(): Kernel’s version of printf() for logging messages
  • KERN_INFO: Log level for informational messages
  • Module metadata: MODULE_* macros provide information about the module
