Installing Debian in a virtualized environment

3 min

Need a safe sandbox to test drivers or experiments without risking your main OS? A virtual machine (VM) is a fast, safe way to do it with KVM/QEMU.

Prerequisites#

  • A Debian/Ubuntu host with hardware virtualization
  • CPU virtualization enabled in BIOS/UEFI (Intel VT-x or AMD-V)

Quick checks:

# CPU supports virtualization? (>0 means yes)
egrep -c '(vmx|svm)' /proc/cpuinfo
lscpu | grep -i virtualization || true

# Optional on Ubuntu: sudo apt install cpu-checker && kvm-ok

Installation#

Let’s update the system and install the necessary tools:

1
2

sudo apt update
sudo apt install -y qemu-kvm libvirt-daemon-system virt-manager virt-viewer ovmf

This gives you:

qemu-kvm       → KVM hypervisor
libvirt-*      → Libvirt service/daemon
virt-manager   → GUI for managing VMs
virt-viewer    → Lightweight viewer
ovmf           → UEFI firmware (OVMF) support

sudo systemctl enable --now libvirtd

# Add your user to the libvirt group (log out/in or use newgrp)
sudo usermod -aG libvirt "$USER"
newgrp libvirt

# Ensure the default NAT network is up
sudo virsh net-start default || true
sudo virsh net-autostart default

Validate everything is ready:

1
2

virsh list --all     # should run without sudo
lsmod | grep kvm     # should show kvm and kvm_intel/amd

Create a VM#

Using the GUI (virt-manager)#

  1. Open Virt-Manager → File → New Virtual Machine
  2. Choose “Local install media (ISO)” and select your Debian ISO
  3. Allocate CPU/RAM (e.g., 2 vCPU, 4 GB RAM) and disk (e.g., 20 GB)
  4. Firmware: choose UEFI if available (OVMF installed)
  5. Finish and follow the Debian installer

Using the CLI (virt-install)#

Download a debian net inst (or the version you want) and replace the ISO path with your actual file path, take a look at this link:

 https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/

virt-install \
  --name debian-kernel-playground \
  --ram 4096 --vcpus 2 \
  --disk size=20,bus=virtio \
  --cdrom /path/to/<replace with iso file> \
  --os-variant debian12 \
  --network network=default,model=virtio \
  --graphics spice \
  --cpu host \
  --machine q35,accel=kvm \
  --boot uefi

Preview#

Follow the instructions in the screen to install the debian distro, probably you don’t need Desktop server, or HTTP server, pick your desired software and you are all set.

Re-launch#

Here are the two common ways to relaunch it. Use whichever matches how you created it.

If you used virt-manager (GUI)#

  1. Open Virtual Machine Manager (run virt-manager or find it in your menu).
  2. In the left pane, connect to QEMU/KVM (qemu:///system).
  3. Select your VM (e.g., debian-kernel-playground) and click ▶️ Start.
  4. Double-click the VM to open the console window.

If you’re using libvirt from the terminal#

# List VMs managed by the system daemon
virsh list --all

# (If nothing appears, try the user session)
virsh -c qemu:///session list --all

# Start it (replace with your VM name)
virsh start debian-kernel-playground

# Open a viewer window
virt-viewer debian-kernel-playground
# or
virt-manager --show-domain-console debian-kernel-playground

Where#

  • virsh start debian-kernel-playground: starts the VM (does not open a GUI)
  • virt-viewer debian-kernel-playground: opens a viewer window to the VM desktop
  • virt-manager --show-domain-console debian-kernel-playground: opens the console in Virt‑Manager

Conclusion#

KVM/QEMU with libvirt gives you a fast, reliable way to run Debian safely alongside your main OS. You can create and manage VMs with either the GUI (virt‑manager) or the CLI (virt‑install/virsh), and enable better performance with VirtIO and UEFI (OVMF).
